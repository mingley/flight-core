# Safety contract (traceability)

Single-source tables live in `define_aerial_authority!` (`safety.rs`) and
are aliased by `vehicle_contract! { from_kernel }`. This file is the
human-readable copy those tables emit (`human_readable_spec()`). IDs are
stable; do not reuse a retired id.

## Capabilities

### FC-CAP-AerialOffboard

```
capability AerialOffboard {
  requires heartbeat.age < 250.ms();
  requires command.age < 100.ms();
  revokes_on [TriggerFailsafe, Disarm, Disconnect, HeartbeatStale, EstimatorInvalid, ImuUnhealthy]
  commands [set_velocity, set_position, hold]
}
```

Generates (one expansion in the kernel, aliased by the capability type):

- kernel [`event_revokes_authority`](../crates/flight-core/src/safety.rs) / `heartbeat_age_ok` / `command_age_ok` / `admit_offboard_command` / `estimator_ts_monotonic`
- Creusot `ensures` on `event_revokes_authority` (same event list)
- Rust capability `AerialOffboard` (`REVOKE_ON` is `AUTHORITY_REVOKE_EVENTS`; `admit` is `admit_offboard_command`; `inject` is `Some` iff `revokes`)
- typestate methods generated by `with_aerial_offboard_commands!` → `impl_aerial_offboard_now!` (`admit_offboard_now`, each kernel command's `*_now` / async wrapper, `for_each_offboard_now`, `leftover_commands_stale`, `apply_velocity_command_now`; `COMMANDS` is `AERIAL_OFFBOARD_COMMANDS`)
- runtime monitors (`AerialOffboard::evaluate` / `Requirement::OffboardAdmitted`, `OffboardHeartbeatFresh`, `CommandAgeMs`, `EstimatorTimestampsMonotonic`, `EpochBumped`; heartbeat/command/estimator monitors fail closed against `HeartbeatFresh` / `CommandFresh` / `Timestamp`)
- Kani harness `dsl_revokes_match_kernel` via `prove_aerial_authority!` (table membership + bounds + admit)
- Kani harness `permit_epoch_mismatch_is_stale`
- mermaid (`AerialOffboard::MERMAID`, [`docs/generated/aerial-offboard.mmd`](generated/aerial-offboard.mmd))
- Graphviz (`AerialOffboard::GRAPHVIZ`, [`docs/generated/aerial-offboard.dot`](generated/aerial-offboard.dot))
- transition table (`AerialOffboard::TRANSITIONS`, [`docs/generated/aerial-offboard.transitions.md`](generated/aerial-offboard.transitions.md))
- Creusot obligations generated by `define_aerial_authority!` (`AerialOffboard::CREUSOT`, [`docs/generated/aerial-offboard.creusot.txt`](generated/aerial-offboard.creusot.txt); `cargo creusot` still proves 81 libraries on `safety` / `ground` / `marine` / `hitl`)
- fault-injection list (`REVOKE_ON` / `inject` / `FAULTS` / `run_revoke_table` leftover Offboard `COMMANDS`, PX4 `inject_revoke` / `run_px4_revoke_table` / `run_px4_leftover_contracts` / `flight-test-px4`, ArduPilot `inject_revoke` / `run_ardupilot_revoke_table` / `run_ardupilot_leftover_contracts` / `flight-test-ardupilot`, HITL `leftover_after_deadline_miss` / `run_hitl_revoke_table` / `run_hitl_leftover_contracts` / `flight-test-hitl`, ROS 2 `leftover_after_failsafe` / `run_ros2_revoke_table` / `run_ros2_leftover_contracts` / `flight-test-ros2`, [`docs/generated/aerial-offboard.faults.md`](generated/aerial-offboard.faults.md) / [`aerial-offboard.faults.txt`](generated/aerial-offboard.faults.txt))
- compile-fail names (`AerialOffboard::UI_FORBIDDEN`, including `unsafe_mission.rs`)
- this specification (`AerialOffboard::SPEC`, [`docs/generated/aerial-offboard.spec.txt`](generated/aerial-offboard.spec.txt))
- [`docs/generated/traceability.md`](generated/traceability.md)

A unit test fails if `AerialOffboard::REVOKE_ON` is not the kernel table.

## Invariants

| ID | Statement | Compile-time | Runtime |
| --- | --- | --- | --- |
| FC-INV-001 | `actuators_enabled → armed` | kernel `check_invariants`, Kani `actuators_require_arm` | `Requirement::ActuatorsImplyArmed` |
| FC-INV-002 | `ActuationPermit.epoch == backend.epoch` | non-`Clone` permit | `permit.check` at the backend boundary; reconnect / `begin_session` bumps epoch; leftover Armed cannot `set_motor_thrust_now`; leftover Takeoff cannot `declare_airborne_now`; PX4/ArduPilot/`NullBackend`/`SimBackend`/`WorldBackend` refuse offboard/climb/actuators/thrust/yaw after `actuation_revoked`; `GroundWorldBackend` / `MarineWorldBackend` refuse drive/thrust/pose/yaw after plant E-stop/failsafe |
| FC-INV-003 | Offboard heartbeat age `< 250 ms` | `Fresh<(), 250>` / `HeartbeatFresh` | `heartbeat_age_ok`, `Requirement::OffboardHeartbeatFresh` |
| FC-INV-004 | Command age `< 100 ms` at actuation | `Command` / `Timestamp` / `command_age_ok` | `Requirement::CommandAgeMs`, `apply_velocity_command_now` |
| FC-INV-005 | Estimator timestamps never jump backward | `estimator_ts_monotonic` | `Requirement::EstimatorTimestampsMonotonic` |

## Fault laboratory

`flight_sim::scenario::Scenario::GPS_LOSS` injects an invalid
`Estimate` (`Estimate::revoke_event` → `EstimatorInvalid`) on the
verified world, then evaluates the same `Requirement` set. A bound
`Vehicle<Offboard>` cannot `set_position_now` after that inject.
`run_revoke_table` injects every `REVOKE_ON` event through
`AerialOffboard::inject`; a leftover Offboard handle cannot run
`set_velocity` / `set_position` / `hold`. `differential_revoke_table`
re-evaluates those leftover samples on JSONL and ULog.
Replay is
`evaluate_trace` on a recorded `TraceSample` JSONL **or** a native ULog
(`fc_trace`, plus a `vehicle_status` subset). PX4 SITL conformance uses
that evaluator on converted traces — they do not require a second contract
language. `differential_contract` is the same monitors on world, replay, and
ulog; gps-loss also runs the checked-in SITL corpus.
PX4 leftover after every `REVOKE_ON` is `run_px4_revoke_table`; leftover
contracts (`gps-loss`, `heartbeat-stale`, `hitl-miss`, `imu-loss` on
`AerialOffboard::LEFTOVER_CONTRACTS`) are `run_px4_leftover_contracts` /
`cargo run -p flight-px4 --bin flight-test-px4`. Live SIH leftover
(`LeftoverContract::live_sitl_safe`: gps-loss, heartbeat-stale, imu-loss)
is `sitl_gps_loss_revokes_leftover_offboard` (`#[ignore]`; CI job `sitl`).
ArduPilot leftover is
`run_ardupilot_revoke_table` / `run_ardupilot_leftover_contracts` /
`cargo run -p flight-ardupilot --bin flight-test-ardupilot` (loopback-only
live Copter).
HITL leftover after a rack deadline/`Rate` miss is
`WorldRack::leftover_after_deadline_miss`; leftover after every `REVOKE_ON`
is `WorldRack::run_hitl_revoke_table`; leftover contracts are
`WorldRack::run_hitl_leftover_contracts` /
`cargo run -p flight-hitl --bin flight-test-hitl`. Faithful FCH1 UDP mock
(`Fch1UdpCard`, not the in-process plant) is `run_fch1_udp_mock` /
`crates/flight-hitl/corpus/fch1_udp_mock.jsonl`. ROS 2 leftover after
`apply_failsafe`, `apply_disarm`, and every `REVOKE_ON` is `plant::leftover_after_failsafe` /
`leftover_after_disarm` / `run_ros2_revoke_table`; leftover contracts are
`run_ros2_leftover_contracts` / `cargo run -p flight-ros2 --bin flight-test-ros2`.
`leftover_after_disarm` / `run_ros2_revoke_table`; leftover contracts are
`run_ros2_leftover_contracts` / `cargo run -p flight-ros2 --bin flight-test-ros2`.
